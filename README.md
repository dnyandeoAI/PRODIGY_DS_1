📊 World Bank Data Visualization & Distribution Analysis (1960–2024)

This project presents an exploratory data analysis of World Bank time-series data containing country-level indicators from 1960 to 2024. The dataset includes structured attributes such as Country Name, Country Code, Indicator Name, Indicator Code, and annual observations for each year.

🎯 Project Objective

The primary objective of this project is to analyze and visualize the distribution of a selected indicator (e.g., total population) across countries and years. The analysis focuses on:

Understanding data distribution using histograms (for continuous variables)

Comparing categorical data using bar charts

Identifying patterns, trends, and variations across countries

📂 Dataset Features

Multi-country coverage

Annual data from 1960 to 2024

Structured time-series format (wide format)

🛠 Technologies Used

Python

Pandas for data cleaning and transformation

Matplotlib / Seaborn for visualization

Jupyter Notebook for analysis workflow

📈 Key Outcome

The visualizations provide meaningful insights into how indicator values are distributed globally and how they vary across time. This project demonstrates fundamental skills in data cleaning, transformation, and exploratory data analysis (EDA).
